# APL iOS 0.2.0: жест закрытия клавиатуры и адаптивная монетизация

Дата: 01.11.2026. Ветка `feat/ios-020-product-plan-20261101`, PR #296.

## 1. Клавиатура без дополнительной кнопки

- На формах создания/правки прокси (включая цифровой порт), импорта (TextEditor), зашифрованных копий (SecureField), исключений и поиска профилей больше нет отдельной кнопки «Готово»/свернуть клавиатуру.
- Свайп **вверх по содержимому над клавиатурой** вызывает `resignFirstResponder` и возвращает доступ к форме и таббару. Используется одновременное распознавание с прокруткой, а не перехват всех касаний. При наличии iOS 16+ `.scrollDismissesKeyboard(.immediately)` дополняет стандартное поведение при прокрутке. Горизонтальные свайпы не сворачивают клавиатуру.
- Системный жест «Домой» от самого нижнего края экрана не перехватывается. Нативные кнопки Return на клавиатурах и «Отмена» в системных Alert остаются.
- Один адресный XCUITest на подписанном iPhone 13 Simulator: **5/5 типов полей (numberPad, password, multiline, backup password, domain), 1/1 PASS, 42,239 секунды**. Исходный текст и пользовательские VPN-настройки не изменялись.

## 2. Одинаковые высоты рекламных блоков

- У верхнего `SettingsBannerView` и нижнего `NativeHomeAdView` один расчёт доступного экранного пространства `equalAdHeight`: приоритет нижним фиксированным контролам. На небольших устройствах, где native по старым правилам не показывается (`height < 650 pt`), вся безопасная площадь доступна одному inline-баннеру, а не делится пополам. На стандартном iPhone 13 Simulator обе зоны **236 pt**, зазоры между хэдером и верхним объявлением, а также между самими объявлениями **0 pt**. Выбор SDK высоты *креатива* внутри inline-слота сохраняется.
- Основной формат остаётся Yandex Mobile Ads SDK 8.x **adaptive inline**: `.inline(width:geometryWidth,maxHeight:slotAllowance)` с полной доступной шириной. Размер 320×50 не зашит. Вспомогательный fallback — adaptive sticky; отдельно оформленный native-блок продолжает использовать собственный SDK.
- `SettingsBannerView` больше не накладывает лишний жёсткий `frame(minHeight:maxHeight:)` на само содержимое `Banner`. Внешние два слота остаются равными и не мешают SDK выбирать креатив, а нижняя кнопка не перекрывается.
- Геометрический QA `scripts/ios_home_layout_geometry_qa.py` проверяет равенство высот и отсутствие перекрытий. **4/4** состояния VPN (`off`, `connecting`, `connected`, `disconnecting`), 70 pt Connect, Home не скроллится.

## 3. Автообновление и предзагрузка

- По [документации Яндекса](https://ads.yandex.com/helpcenter/ru/easy/integration/ios/formats/banner) iOS-баннеры SDK автоматически обновляются приблизительно **раз в 60 секунд**. Дополнительный собственный таймер или искусственное снятие/повторное создание `BannerState` **не добавлены** во избежание двойных запросов и недействительных показов. Интервал 30 с не устанавливается по предположению: в документации для нестандартного интервала предусмотрено обращение к менеджеру Яндекса.
- SDK уже инициализируется в `ArvectumProxyLauncherApp.init()`. Нативное объявление теперь **предзагружается в ContentView.task до `model.prepare()`**; его контроллер и `NativeAdLoader` живут в `@StateObject` экрана, а не в пересоздаваемом отдельном блоке Home. Это сохраняет загруженное объявление при переходах между вкладками, при этом оно показывается/учитывается как показ только при фактическом отображении.
- По [официальному SwiftUI API](https://ads.yandex.com/helpcenter/en/dev/ios/swiftui/adaptive-inline-banner) `Banner` загружается при появлении в иерархии. Не создаём скрытый баннер ради мнимой предзагрузки: SDK может не засчитать показ без видимости. Сам SDK стартует раньше отрисовки интерфейса.
- [Нативная интеграция SDK](https://ads.yandex.com/helpcenter/en/dev/ios/native) сохраняет сильную ссылку на ad/loader, компоненты рекламы и обратный вызов реальных impression. Ни текст/картинки креативов, ни рекламная атрибуция не менялись.

## 4. Пределы проверки и следующий шаг

- Симулятор и source-контракты подтверждают: **5** сценариев свайпа, **4** состояния геометрии, одинаковые высоты рекламных слотов. Это не измерение будущего CPM или автоматическое доказательство увеличения выручки.
- Финальная физическая проверка живой рекламы, SDK impression и жестов на iPhone после безопасного обновления версии **0.2.0 (48)** остаётся необходимой, если CoreDevice не восстановит доступ к устройству. **Нельзя** удалять установленное приложение или изменять сохранённые профили ради тестирования.
- Расширение локализаций на 48 языков отложено до утверждения интерфейса; Apple App Store/TestFlight публикация в рамках задачи не выполняется.
