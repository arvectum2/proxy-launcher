# GitVerse mirror: надёжная синхронизация по изменённому ref

Дата: 06.11.2026. Источник: `arvectum2/proxy-launcher`. Подзадача `APL-IOS-CI-GITVERSE-REFSCOPED-20261106`, связана с PR #352.

## Наблюдаемый сбой

После внедрения iOS безопасного сообщения об ошибке GitHub Actions `Mirror repository` в трёх последовательных попытках завершился **HTTP 504** (одна попытка выполнялась 60–110 с). На GitHub у репозитория было **529 веток**. Прежний workflow каждый push выполнял `git push --force --prune` одновременно для *всех* веток и тегов, даже если менялся один ref. Чтение `git ls-remote` GitVerse работало, но синхронизация сотен refs обрывалась по таймауту.

## Новая модель

- GitHub `push` существующей ветки/тега синхронизирует **только `GITHUB_REF`** (полный namespaced `refs/heads/...` или `refs/tags/...`) в соответствующий ref GitVerse. Ни чужие refs, ни pull-request refs не трогаются.
- При событии удаления ветки/тега передаётся один направленный delete-refspec `:<ref>` — удаление целиком всех веток на каждом обычном push не выполняется.
- `schedule` (ежедневно) и ручной `workflow_dispatch` по-прежнему выполняют **полную сверку с `--prune`** веток и тегов. Это сохраняет reconciliation и восстановление после пропуска события.
- Все pushes ограничены тремя попытками с задержками 15 и 30 секунд при временной недоступности. После трёх неуспехов workflow **завершается ошибкой**, не подменяя её зелёным статусом. Не логируются токены или URL с реквизитами.
- Требования GitHub CI к merge, права checkout, repository mirror source, отдельная проверка подписи iOS, App Store, работа VPN, Keychain, сетевые маршруты и native FIN PR #314 не изменялись.

## Тесты

`python3 -m unittest -q tests.test_ci_gitverse_refscoped` — 6 POSIX-моков `git`/`sleep` и один кроссплатформенный статический контракт, без обращения к настоящему GitVerse и реального удаления. Проверены branch/tag, удаление по событию, manual/schedule prune, два transient 504-аналога, 3 попытки постоянного отказа, `bash -n`, сохранение триггеров и concurrency. YAML разобран Ruby Psych (`YAML_OK`).

**Фактическая приёмка:** успешная реальная синхронизация текущего изменённого ref в GitVerse через GitHub Actions exact-head workflow и зелёный merge gate, без обхода CI. Пока не завершена — не заявлять, что зеркалирование восстановлено.
