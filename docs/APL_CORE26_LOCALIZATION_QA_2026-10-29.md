# APL Core-26 · урду, бенгальский, панджаби (гурмукхи), тамильский, телугу

Дата: 29.10.2026. Дополнение к PR #272, без изменения опубликованной/отправленной Apple сборки и карточки App Store Connect.

## Объём и терминология

- Полные каталоги Tier-2 языков Arvectum Tools Core: `ur`, `bn`, `pa` (гурмукхи), `ta`, `te`.
- Для каждого **155 iOS + 104 Android + 193 desktop = 452** исходных строк; новая волна **2 260** строк, всего **26 языков × 452 = 11 752** значения пользовательского интерфейса на трёх платформах.
- Переводы сделаны с использованием пакетного машинного перевода по исходным EN/RU текстам, с защитой технических строк, URL, `HTTP`, `HTTPS`, `SOCKS5`, `Network Extension`, `Packet Tunnel` и форматных аргументов. Ни одна строка не оставлена пустой или как англоязычная заглушка.
- Редакторски скорректированы **80 ключевых инструкций** (по 16/язык): iOS Shortcuts, режим работы по приложениям, исключения и связанные домены, системные VPN-разрешения, первоначальная настройка и смена режима. Добавлены **28 стандартизованных терминов на каждый язык**.
- Дополнительно исправлены тексты пяти инструкций экстренного восстановления сети, пять предупреждений о сохранности сетевых настроек других программ и пять сообщений об остановке прокси при неполной сетевой реставрации. Пять подсказок диагностики теперь совпадают с названием фактической кнопки; у текстов-компонентов восстановлены граничные пробелы.
- В iOS Urdu `ur` включает RTL вместе с `ar` и `fa`. В Android `supportsRtl=true`; адреса/порты оставлены LTR. Desktop Tk использует выравнивание надписей справа для `ur/ar/fa`, но полное зеркалирование сетки не заявлено.
- Для панджаби выбран **гурмукхи**: Android квалификатор `values-b+pa+Guru`, в переключателе iOS — `ਪੰਜਾਬੀ (ਗੁਰਮੁਖੀ)`. Для `pa-PK`/`pa-Arab` в iOS системной локали не выбирается этот каталог, чтобы не подменять шахмукхи текстом гурмукхи.
