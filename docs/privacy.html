Arvectum Proxy Launcher — Privacy Policy

Effective date: 28 September 2026 · LLC ARVECTUM

Summary

Arvectum Proxy Launcher (“APL”) is a local network utility. LLC ARVECTUM does not collect, sell, use, or disclose user traffic, browsing history, proxy credentials, device identifiers, analytics data, or advertising data through the current Android, iOS, or macOS apps.

Data collection

The current Android, iOS, and macOS releases do not contain advertising SDKs, analytics SDKs, tracking technologies, user accounts, or an Arvectum cloud backend. The app does not send telemetry or usage analytics to LLC ARVECTUM.

Proxy configuration and credentials

Users provide their own proxy servers. Proxy host, port, profile name, username, routing preferences, exclusions, and connection journal are stored locally on the device. Proxy passwords are protected by platform storage: Android encrypts them with a key held in Android Keystore, while Apple-platform releases use the system Keychain. These values are not transmitted to LLC ARVECTUM.

Network traffic

APL creates a local system VPN/tunnel so selected device traffic can be routed to a proxy chosen by the user. On Android it uses Android VpnService with an embedded open-source packet-forwarding component; on iOS and macOS it uses Apple Network Extension / NEVPNManager APIs. Network traffic is routed from the device to the user-selected proxy and then to the requested destination. LLC ARVECTUM does not operate an intermediary server in the current public release and does not inspect or retain the contents of the traffic.

Local diagnostics

The app may store local connection events needed to show status and diagnose failures. These events are stored on the device and are designed not to contain proxy passwords or the contents of user traffic. A user may delete app data by removing the app from the device.

Third parties

The app uses operating-system networking and security services plus embedded open-source packet-forwarding components. LLC ARVECTUM does not share app-derived user data with advertisers, data brokers, analytics providers, or an Arvectum cloud service. When the user enables the tunnel, network traffic is necessarily sent to the proxy endpoint that the user explicitly configured and then to the destination service requested by the user. Those proxy operators and destination services are independent third parties selected or contacted by the user; LLC ARVECTUM does not control whether they retain data and does not receive a copy of that traffic. Operating-system vendors and the app store used to obtain the app may also process their own account, download, security, or device information independently under their own terms and privacy policies.

Children

APL is a general-purpose network utility and is not designed to collect personal information from children. The app does not knowingly collect personal information from any user.

Changes

If a future release introduces data collection, analytics, advertising, accounts, or cloud services, this policy and the in-app disclosure will be updated before those features are enabled.

Политика конфиденциальности

Arvectum Proxy Launcher — локальная сетевая утилита. ООО «Арвектум» не собирает, не продаёт и не получает пользовательский трафик, историю посещений, данные прокси, идентификаторы устройства, аналитику или рекламные данные через текущие приложения Android, iOS и macOS. Адрес, порт, логин, настройки маршрутизации и локальный журнал хранятся на устройстве. На Android пароль прокси шифруется ключом из Android Keystore; на платформах Apple используется системная Связка ключей. APL создаёт локальный системный VPN/туннель и направляет выбранный трафик через прокси, который пользователь явно указал сам, а затем к запрошенному пользователем сервису: на Android используется VpnService, на iOS и macOS — Network Extension / NEVPNManager. Выбранный пользователем оператор прокси и запрошенный сервис являются независимыми третьими лицами; ООО «Арвектум» не получает копию этого трафика и не контролирует правила хранения данных такими сервисами. В текущей публичной версии серверы ООО «Арвектум» не находятся в пути пользовательского трафика. В приложении нет рекламы, аналитики, трекинга, регистрации или облачного backend.
