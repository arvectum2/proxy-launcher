Arvectum Proxy Launcher — Privacy Policy

Effective date: 25 September 2026 · LLC ARVECTUM

Summary

Arvectum Proxy Launcher (“APL”) is a local network utility. LLC ARVECTUM does not collect, sell, use, or disclose user traffic, browsing history, proxy credentials, device identifiers, analytics data, or advertising data through the iOS app.

Data collection

The current iOS release does not contain advertising SDKs, analytics SDKs, tracking technologies, user accounts, or an Arvectum cloud backend. The app does not send telemetry or usage analytics to LLC ARVECTUM.

Proxy configuration and credentials

Users provide their own proxy servers. Proxy host, port, profile name, username, routing preferences, exclusions, and connection journal are stored locally on the device. Proxy passwords are stored in the iOS Keychain. These values are not transmitted to LLC ARVECTUM.

Network traffic

APL uses Apple Network Extension / NEVPNManager APIs to create a local packet-tunnel configuration. Network traffic is routed from the device to the proxy selected by the user and then to the destination requested by the user. LLC ARVECTUM does not operate an intermediary server in this traffic path and does not inspect or retain the contents of the traffic.

Local diagnostics

The app may store local connection events needed to show status and diagnose failures. These events are stored on the device and are designed not to contain proxy passwords or the contents of user traffic. A user may delete app data by removing the app from the device.

Third parties

The app uses operating-system services provided by Apple and an embedded open-source packet forwarding component. LLC ARVECTUM does not share app-derived user data with advertisers, data brokers, or analytics providers. Apple may process information independently when a user downloads or uses apps according to Apple’s own terms and privacy policies.

Children

APL is a general-purpose network utility and is not designed to collect personal information from children. The app does not knowingly collect personal information from any user.

Changes

If a future release introduces data collection, analytics, advertising, accounts, or cloud services, this policy and the in-app disclosure will be updated before those features are enabled.

Политика конфиденциальности

Arvectum Proxy Launcher — локальная сетевая утилита. ООО «Арвектум» не собирает, не продаёт, не использует и не передаёт третьим лицам пользовательский трафик, историю посещений, данные прокси, идентификаторы устройства, аналитику или рекламные данные через iOS-приложение. Адрес, порт, логин, настройки маршрутизации и локальный журнал хранятся на устройстве; пароль прокси — в Связке ключей iOS. APL использует Network Extension / NEVPNManager для направления трафика через прокси, выбранный пользователем. Серверы ООО «Арвектум» не находятся в пути пользовательского трафика. В текущей версии нет рекламы, аналитики, трекинга, регистрации или облачного backend.
