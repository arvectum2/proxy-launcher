# APL iOS — диагностика подключения, этап 1 (31.10.2026)

## Область изменений

Проверка каждого профиля через `ProxyProbe` возвращает типизированную, краткую причину недоступности в меню выбора прокси. Никакие адреса серверов, логины, пароли и сырые системные ошибки не включаются в диагностический код. Текущие 50 локализованных каталогов iOS не изменяются: слово «недоступен» берётся из `AppL10n.tr`, к нему добавляется нейтральный технический код.

| Код | Значение |
| --- | --- |
| `NET` | Сеть отключена или маршрутизация до сервера недоступна |
| `DNS` | Не удалось разрешить имя хоста |
| `TCP` | TCP-соединение отклонено или разорвано |
| `TLS` | Ошибка защищённого соединения |
| `AUTH` | Ошибка SOCKS5-авторизации |
| `HTTP 407` | HTTP CONNECT потребовал или отклонил авторизацию; `Digest 407` больше не считается успехом |
| `PROXY` | Сервер отказал в создании туннеля |
| `TIMEOUT` | Истёк срок ожидания соединения |
| `PROTOCOL` | Некорректный/неподдерживаемый ответ прокси |
| `VPN` | Ошибка системной конфигурации/запуска Network Extension |
| `UNKNOWN` | Неизвестная ошибка; не выдумывать причину |

AUTO-пробы собирают только категории от нескольких проверенных типов прокси и возвращают наиболее информативный результат, не копируя исходные тексты исключений. Конкурентная проверка профилей использует поколение сканирования, чтобы старые асинхронные ответы не перезаписывали более новые. Continuation `NWConnection` защищён от повторного resume потокобезопасным gate.
