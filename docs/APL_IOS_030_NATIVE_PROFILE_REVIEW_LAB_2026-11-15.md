# Native profile and encrypted backup review rehearsal

The app has an explicitly gated `DEBUG && APL_NATIVE_PROFILE_REVIEW && targetEnvironment(simulator)` QA screen reachable from the backup sheet. The default project does not define this flag. The English QA labels are deliberate, not final product localization. No shipping UI, product profile model, real Keychain, VPN, CloudKit, or entitlements are changed.

`NativeProfileReviewSession` owns its own ephemeral memory catalog and records. It reuses the native compiler, single-use review and journaled additive restore contract. The rehearsal's injected inactive guard is true because it owns no VPN object; it is never a valid OS check for a real restore. Imported text is bounded, displayed results contain only per-protocol counts and backup export receives authenticated ciphertext only. A failed preview, cancel, or expired confirmation cannot commit; closing the sheet clears memory references. This does not promise secure zeroization. The original storage-bound user flow still needs exclusive real OS coordination, signed cross-process Keychain and UI acceptance.

## Review lifecycle hardening

One outstanding file action has a unique receipt carrying the exact selected protocol or backup/export operation. Core rejects stale, duplicate and cancelled receipts. The QA view captures receipts at presentation, clears temporary records and password/file references on background and dismissal, supplies explicit recovery for cancelled panels, and uses unique encrypted export filenames. Actual SwiftUI callback delivery, Files picker and background lifecycle behavior remain unaccepted until S1 in the remaining acceptance runbook. Swift361/361, Python417/417+1527, gated simulator Debug and unsigned Release PASS; normal QA UI and experimental engine markers absent.

QA-only 21 labels now localized RU/EN with English fallback for other languages. No changes to the 64 shipping dictionaries. Native backup accepts at most 4096 UTF-8 password bytes (existing character-count rule retained); legacy password rules unchanged. Shared envelope rejects ciphertext exceeding the existing plaintext limit + 28-byte AES-GCM overhead before PBKDF2. Swift363/363, Python418/418+1527, both builds PASS; GUI/Files acceptance remains open.

## Step 2 — product-facing library presentation contract

The simulator-only flag now exposes a separate native review library entry on the existing Profiles screen as well as the backup sheet. The normal HTTP/HTTPS/SOCKS5 profile list, selection, editing and bulk actions are unchanged. Each native row is projected from catalog metadata only: ordinal, protocol, opaque revision/reference, review selection, and explicit unavailable/review-only state. Schema migration, unfinished journal, legacy ID collision and exclusions prevent review selection. The capability model never advertises a working connection; there is no Connect action. Legacy IDs and current site exclusion presence are read-only inputs to this simulator preview, not evidence of real-time OS policy enforcement.
