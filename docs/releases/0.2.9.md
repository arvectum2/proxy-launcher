# Arvectum Proxy Launcher 0.2.9

Stable recovery-symmetry release for Windows x64, Astra Linux 1.8 x86-64 and RED OS 8.0.3 x86-64.

## Русский

### Главное

0.2.9 доводит Windows rollback до той же ownership-модели, которая уже действует в Linux 0.2.8. Перед восстановлением Proxy Launcher теперь сначала проверяет текущее состояние WinINET и пользовательских `HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY` / `NO_PROXY`.

Каждое управляемое поле должно быть либо исходным сохранённым значением, либо точным значением, применённым Arvectum. Если пользователь или администратор во время работы launcher выставил третий PAC, manual proxy или proxy environment, автоматический rollback не перезаписывает это более новое состояние: операция завершается fail-closed, а rollback evidence сохраняется для явного восстановления. Частично возвращённый к исходному состоянию Arvectum proxy остаётся безопасно восстанавливаемым.

Windows restore теперь выполняет общий preflight обоих контуров до первой записи, поэтому отказ в proxy environment не может оставить уже частично восстановленный WinINET. Astra Linux / GSettings и RED OS / KDE сохраняют проверенную в 0.2.8 saved-or-Arvectum semantics без изменений.

## English

### Highlights

0.2.9 brings Windows rollback ownership semantics in line with the Linux saved-or-Arvectum model introduced in 0.2.8. Before restoration, Proxy Launcher now preflights the current WinINET state and per-user `HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY` / `NO_PROXY` values.

Each governed field must equal either its saved original value or the exact value applied by Arvectum. If a user or administrator introduces a third PAC, manual proxy, or proxy environment while the launcher is active, automatic rollback preserves that newer state and fails closed while retaining rollback evidence for explicit recovery. Partially reverted Arvectum-owned state remains safely recoverable.

Windows restore now preflights both ownership contours before the first mutation, preventing an environment conflict from leaving WinINET partially restored. Astra Linux / GSettings and RED OS / KDE retain the 0.2.8 saved-or-Arvectum behavior unchanged.
