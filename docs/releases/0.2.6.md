# Arvectum Proxy Launcher 0.2.6

## Русский

### Что это за релиз

Arvectum Proxy Launcher 0.2.6 — стабильный кроссплатформенный релиз для Windows x64 и Astra Linux 1.8 x86-64.

Главное изменение Linux/Astra: исправлена интеграция Firefox в режиме **«Использовать системные настройки прокси»**. На Astra/Fly 0.2.5 публиковал PAC через NetworkManager, тогда как Firefox читал desktop GSettings. В 0.2.6 Proxy Launcher управляемо публикует PAC в оба системных контура и сохраняет точный rollback/recovery и защиту от внешних изменений.

### Что скачивать

Windows:
- `Arvectum-Proxy-Launcher-0.2.6-windows-x64-setup.exe` — обычная установка;
- `Arvectum-Proxy-Launcher-0.2.6-windows-x64-portable.zip` — portable.

Astra Linux:
- `Arvectum-Proxy-Launcher-0.2.6-astra-linux-amd64.deb` — пакет amd64.

Все три пакета покрыты `SHA256SUMS.txt`.

### Astra Linux

Linux-пакет зависит от `network-manager` и `libglib2.0-bin`. Пакет устанавливает приложение, launcher, desktop entry, icon и license notices, но намеренно не содержит maintainer scripts, которые могли бы менять proxy state во время установки.

Установка:

```bash
sudo apt install ./Arvectum-Proxy-Launcher-0.2.6-astra-linux-amd64.deb
```

Путь Firefox system-proxy и точный rollback были физически проверены на Astra Linux 1.8/Fly в ходе APL-LNX-010/APL-LNX-011. Публичный DEB берётся из успешного exact-main CI для Ubuntu 22.04 того же release commit и дополнительно проверяется как Debian package перед публикацией.

### Windows

Windows system-proxy path отдельно проверен после Linux-исправления: аналогичного split-settings-plane дефекта не обнаружено. Windows продолжает публиковать PAC в HKCU WinINET `AutoConfigURL`, отключает параллельный manual proxy и вызывает WinINET settings refresh. В 0.2.6 добавлена регрессия, защищающая этот контракт.

### GitVerse

GitHub остаётся каноническим источником release bytes. GitVerse зеркалирует тот же релиз независимо. Расширения, которые GitVerse не принимает напрямую (включая `.exe` и `.deb`), переносятся в детерминированных однофайловых ZIP-обёртках. После публикации workflow скачивает GitVerse assets и сверяет SHA-256 исходных payload с каноническими GitHub bytes.

### Trust boundary

0.2.6 не заявляет Microsoft Authenticode-подпись. Отдельная российская detached CryptoPro/Rutoken-подпись релиза 0.2.5 является историческим evidence-контуром и не считается подписью 0.2.6 без нового owner-operated signing gate.

## English

### About this release

Arvectum Proxy Launcher 0.2.6 is the stable cross-platform release for Windows x64 and Astra Linux 1.8 x86-64.

The primary Linux/Astra change fixes Firefox **Use system proxy settings** integration. On Astra/Fly, 0.2.5 published PAC through NetworkManager while Firefox consumed desktop GSettings. Version 0.2.6 governably publishes PAC to both settings planes while preserving exact rollback/recovery and foreign-change protection.

### What to download

Windows:
- `Arvectum-Proxy-Launcher-0.2.6-windows-x64-setup.exe` — normal installer;
- `Arvectum-Proxy-Launcher-0.2.6-windows-x64-portable.zip` — portable package.

Astra Linux:
- `Arvectum-Proxy-Launcher-0.2.6-astra-linux-amd64.deb` — amd64 Debian package.

All three packages are covered by `SHA256SUMS.txt`.

### Astra Linux

The Linux package depends on `network-manager` and `libglib2.0-bin`. It installs the application, launcher, desktop entry, icon, and license notices, while intentionally shipping no maintainer scripts that could mutate proxy state during package installation.

Install with:

```bash
sudo apt install ./Arvectum-Proxy-Launcher-0.2.6-astra-linux-amd64.deb
```

The Firefox system-proxy path and exact rollback were physically exercised on Astra Linux 1.8/Fly during APL-LNX-010/APL-LNX-011. The public DEB is taken from the successful exact-main Ubuntu 22.04 CI run for the same release commit and is inspected as a Debian package before publication.

### Windows

The Windows system-proxy path was audited after the Linux fix and no analogous split-settings-plane defect was found. Windows continues to publish PAC through HKCU WinINET `AutoConfigURL`, disables parallel manual proxy, and refreshes WinINET consumers. Version 0.2.6 includes regression coverage for this contract.

### GitVerse

GitHub remains the canonical source of release bytes. GitVerse independently mirrors the same release. Extensions GitVerse does not accept directly, including `.exe` and `.deb`, are transported in deterministic single-file ZIP wrappers. After publication, the workflow downloads GitVerse assets and verifies the original payload SHA-256 values against the canonical GitHub bytes.

### Trust boundary

Release 0.2.6 does not claim Microsoft Authenticode signing. The separate Russian detached CryptoPro/Rutoken signature published for release 0.2.5 is historical evidence and is not considered a 0.2.6 signature without a new owner-operated signing gate.
