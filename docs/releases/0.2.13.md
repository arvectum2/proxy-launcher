# Arvectum Proxy Launcher 0.2.13

Patch release focused on the completed macOS stabilization cycle and the first public macOS beta DMGs.

The published v0.2.12 release, tag, and assets remain immutable. 0.2.13 is a new release.

## Русский

### Что изменилось

- **macOS Safari / ChatGPT:** устранён реальный обход системного proxy после reload. На macOS CFNetwork начинал отправлять часть трафика напрямую по IPv6, когда итоговый `ExceptionsList` становился слишком большим. APL теперь сохраняет системный baseline и ограничивает свой effective bypass-list безопасным пределом **47 записей**.
- **macOS direct-upstream:** системные HTTP/HTTPS настройки при включённом APL направляются напрямую на выбранный upstream proxy; Safari/Chrome больше не зависят от localhost relay для системного web-трафика.
- **macOS rollback:** полный план восстановления теперь проверяется **до** остановки worker. APL больше не должен оставлять macOS с включённым SOCKS на уже остановленный localhost endpoint.
- **Disabled PAC drift:** исчезновение запомненного URL у выключенного PAC больше не считается чужим изменением сети и не блокирует корректный rollback.
- **Wake/UI recovery:** сохранены исправления ownership/PID, ложного `STOPPED`, wake/HID guard, deferred Off confirmation и lifecycle UI race.
- **Telegram на тестовом MacBook:** отдельный legacy SOCKS `127.0.0.1:1080` остаётся независимым от APL; это локальная совместимость конкретной машины, а не обязательная часть установки APL.
- **Проверено физически на Apple Silicon:** Safari с включённым APL — отправка сообщения, получение ответа и reload страницы прошли успешно; Off/rollback также проверен.
- **Экспериментальный NetworkExtension не включён:** незавершённый native Transparent Proxy prototype сохранён отдельно в ветке `experiment/macos-transparent-proxy-extension` и не входит в 0.2.13.

### macOS beta DMG

Впервые к релизу прикладываются скачиваемые DMG:

- `Arvectum-Proxy-Launcher-0.2.13-macos-arm64.dmg` — Apple Silicon (M1/M2/M3/M4 и новее).
- `Arvectum-Proxy-Launcher-0.2.13-macos-x64.dmg` — Intel Mac.

**Важно:** эти DMG собраны canonical exact-main CI, но пока **не подписаны Developer ID и не notarized Apple**. Это beta-дистрибутив. Apple Silicon сборка прошла физический acceptance; Intel DMG проходит native Intel CI packaging/verification, но в этом цикле не проходил отдельный физический пользовательский acceptance.
Установка:

1. Скачайте DMG для своей архитектуры.
2. Откройте DMG и перетащите **Arvectum Proxy Launcher** в **Applications**.
3. Попробуйте запустить приложение.
4. Если macOS заблокирует запуск, откройте **System Settings → Privacy & Security** и нажмите **Open Anyway** для Arvectum Proxy Launcher, затем подтвердите запуск.

Не отключайте Gatekeeper глобально и не используйте `xattr -dr` для всей системы.

## English

### Changes

- **macOS Safari / ChatGPT:** fixed the observed post-reload proxy bypass. CFNetwork could send some traffic directly over IPv6 when the effective proxy `ExceptionsList` became too large. APL now preserves the baseline and caps its owned effective bypass list at a verified safe ceiling of **47 entries**.
- **macOS direct upstream:** while APL is enabled, system HTTP/HTTPS routing points directly to the selected upstream proxy; Safari/Chrome no longer depend on a localhost relay for system web traffic.
- **macOS rollback:** the complete restore plan is validated **before** worker termination, preventing a dead localhost SOCKS route from being left active after a refused rollback.
- **Disabled PAC drift:** disappearance of the remembered URL for an already disabled PAC no longer blocks rollback.
- **Wake/UI recovery:** ownership/PID recovery, false `STOPPED` protection, wake/HID destructive-action guard, deferred Off confirmation and lifecycle UI race fixes are retained.
- **Apple Silicon physical acceptance:** Safari with APL enabled successfully completed send → response → page reload, and Off/rollback was also verified.
- **Experimental NetworkExtension excluded:** the unfinished native Transparent Proxy prototype is preserved separately on `experiment/macos-transparent-proxy-extension` and is not part of 0.2.13.
### macOS beta DMG

This is the first release with downloadable macOS DMGs:

- `Arvectum-Proxy-Launcher-0.2.13-macos-arm64.dmg` — Apple Silicon.
- `Arvectum-Proxy-Launcher-0.2.13-macos-x64.dmg` — Intel Mac.

These DMGs are canonical exact-main CI artifacts, but they are currently **ad-hoc signed and not Apple-notarized**. They are beta distribution assets, not production Developer ID builds. Apple Silicon has real-host acceptance; Intel is native Intel CI-packaged/verified but was not separately user-accepted in this cycle.

Install:

1. Download the DMG matching your Mac.
2. Open it and drag **Arvectum Proxy Launcher** to **Applications**.
3. Try to launch the app.
4. If macOS blocks it, open **System Settings → Privacy & Security → Open Anyway**, then confirm.

Do not globally disable Gatekeeper.
