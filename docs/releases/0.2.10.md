# Arvectum Proxy Launcher 0.2.10

Stable cross-platform maintenance release with macOS recovery/UI hardening and the first public Linux AppImage package.

## Русский

### Главное

**0.2.10** продолжает стабильную публичную линию Windows x64, Astra Linux 1.8 x86-64 и RED OS 8.0.3 x86-64 и впервые добавляет переносимый Linux AppImage в канонический release set.

На macOS завершён отдельный цикл реального acceptance на Apple Silicon:

- исправлено восстановление PAC после частичного/ручного rollback;
- чужой совместимый localhost PAC/process больше не может ошибочно считаться процессом Arvectum;
- автозапуск переведён на ownership-safe per-user LaunchAgent вместо Windows/portable логики;
- интерфейс использует нативную Aqua-тему, системные Light/Dark colors и macOS controls;
- иконка приведена к нормальному macOS optical size и прозрачному squircle;
- реальный цикл `enable -> HTTP/SOCKS/PAC -> stop -> exact restore` повторно проверен на Mac mini.

Эти macOS-изменения входят в исходный код 0.2.10, но **публичный macOS DMG в 0.2.10 не публикуется**. Текущая локальная сборка использует ad-hoc code signing; production distribution остаётся отдельным gate для Apple Developer ID signing/notarization. Релиз не выдаёт локальную ad-hoc сборку за production-signed macOS package.

### Linux AppImage

0.2.10 — первый публичный релиз с:

- `Arvectum_Proxy_Launcher-0.2.10-x86_64.AppImage`

AppImage собирается из того же канонического Linux frozen application, использует hash-pinned AppImage toolchain/runtime, включает runtime/third-party notices и публикуется только из успешного exact-main CI артефакта.

DEB остаётся предпочтительным native package для Astra Linux, RPM — для RED OS; AppImage предназначен для переносимого generic-Linux сценария.

### Публичные пакеты

- `Arvectum-Proxy-Launcher-0.2.10-windows-x64-setup.exe`
- `Arvectum-Proxy-Launcher-0.2.10-windows-x64-portable.zip`
- `Arvectum-Proxy-Launcher-0.2.10-astra-linux-amd64.deb`
- `Arvectum-Proxy-Launcher-0.2.10-redos-linux-x86_64.rpm`
- `Arvectum_Proxy_Launcher-0.2.10-x86_64.AppImage`
- `SHA256SUMS.txt`

Все публичные package bytes должны соответствовать `SHA256SUMS.txt`.

0.2.10 не заявляет Microsoft Authenticode, Apple Developer ID/notarization или новую detached CryptoPro/Rutoken подпись. Эти trust/signing gates остаются отдельными от функциональной корректности.

## English

### Highlights

**0.2.10** continues the stable public Windows x64, Astra Linux 1.8 x86-64 and RED OS 8.0.3 x86-64 tracks and adds the first canonical public Linux AppImage.

The macOS engineering baseline received another real Apple Silicon acceptance cycle:

- PAC rollback now handles partially/manual-restored states safely;
- a foreign compatible localhost PAC/process can no longer be mistaken for the Arvectum engine;
- autostart now uses an ownership-safe per-user LaunchAgent instead of Windows/portable logic;
- the UI now uses native Aqua, system Light/Dark semantic colors and macOS controls;
- the app icon uses a transparent squircle at normal macOS optical scale;
- a live `enable -> HTTP/SOCKS/PAC -> stop -> exact restore` cycle was re-verified on a Mac mini.

These macOS changes are part of the 0.2.10 source tree, but **0.2.10 does not publish a public macOS DMG**. The current local build is ad-hoc signed; production distribution remains a separate Apple Developer ID signing/notarization gate. The release does not present an ad-hoc local build as a production-signed macOS package.

### Linux AppImage

0.2.10 is the first public release to include:

- `Arvectum_Proxy_Launcher-0.2.10-x86_64.AppImage`

The AppImage is built from the same canonical Linux frozen application, uses the hash-pinned AppImage toolchain/runtime, embeds runtime and third-party notices, and is published only from the successful exact-main CI artifact.

DEB remains the preferred native package for Astra Linux and RPM remains the preferred package for RED OS; AppImage is the portable generic-Linux option.
