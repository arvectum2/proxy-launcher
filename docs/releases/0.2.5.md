# Arvectum Proxy Launcher 0.2.5

## Русский

### Что это за релиз

Arvectum Proxy Launcher 0.2.5 — стабильный Windows-релиз с исправленным установщиком и безопасным переносом рабочего runtime в `%LOCALAPPDATA%\Programs\ArvectumProxyLauncher`.

Версия 0.2.5 прошла физическую проверку на Windows: установка, автозапуск после перезагрузки, PAC, локальный HTTP proxy и отсутствие старого Python-runtime были подтверждены на реальной машине. Публичный набор релиза дополнительно связан SHA-256 manifest и detached CryptoPro/Rutoken signature сертификатом ООО «Арвектум».

Для запуска без установки:

`Arvectum-Proxy-Launcher-0.2.5-windows-x64-portable.zip`

SHA-256:

### Установка на Windows

1. Скачайте Setup с этой страницы релиза.
2. Запустите скачанный EXE.
3. Windows может показать Microsoft Defender SmartScreen: **«Система Windows защитила компьютер»**. Это ожидаемо для 0.2.5: Setup пока не имеет Microsoft Authenticode-подписи.
4. Нажмите **«Подробнее» → «Выполнить в любом случае»**.
5. Подтвердите стандартный запрос UAC, если он появится.
6. После установки запускайте **Arvectum Proxy Launcher** из меню «Пуск».

**Не отключайте Microsoft Defender, SmartScreen или Controlled Folder Access.** Это не требуется для установки и работы приложения.

### Почему Windows показывает SmartScreen

Публичный Setup 0.2.5 не имеет Microsoft Authenticode-подписи. При загрузке из Интернета Windows помечает файл Mark-of-the-Web, поэтому SmartScreen может показать предупреждение для неизвестного издателя. Это предупреждение не означает, что Defender обнаружил вредоносный код.

Целостность официального релиза можно проверить по SHA-256. Дополнительно в assets опубликована российская detached-подпись CryptoPro/Rutoken и сертификат подписанта. Эта подпись подтверждает происхождение и целостность release set, но не заменяет Microsoft Authenticode и не формирует репутацию SmartScreen.

### Проверка SHA-256 Setup

```powershell
Get-FileHash "$env:USERPROFILE\Downloads\Arvectum-Proxy-Launcher-0.2.5-windows-x64-setup.exe" -Algorithm SHA256
```

Ожидаемый результат:

`9b5368d67874b7164ee56a245c75db4b23af593a1d72f7e947774516abcc95e3`

### Что исправлено в 0.2.5

- установка перенесена из пользовательских Documents в `%LOCALAPPDATA%\Programs\ArvectumProxyLauncher`;
- preflight установщика стал read-only и больше не должен останавливать рабочий runtime до безопасной точки handover;
- добавлены stage-and-verify и транзакционный runtime handover с rollback/recovery;
- подтверждён upgrade из исторического Documents-layout;
- подтверждён чистый reboot/autostart сценарий;
- старый Desktop shortcut не создаётся установщиком; штатный ярлык создаётся в меню «Пуск»;
- release set подписан российским CryptoPro/Rutoken evidence-контуром и независимо проверен перед публикацией.

### Проверка российского release set

Для расширенной проверки скачайте все assets релиза в одну папку и запустите `VERIFY_RUSSIAN_RELEASE.cmd`. Проверка подтверждает SHA-256 manifest и detached CryptoPro signature. Она не заявляет Microsoft Authenticode/SmartScreen trust.

## English

### About this release

Arvectum Proxy Launcher 0.2.5 is the stable Windows release with a hardened installer and a safe runtime migration to `%LOCALAPPDATA%\Programs\ArvectumProxyLauncher`.

Version 0.2.5 passed physical Windows acceptance covering installation, clean reboot autostart, PAC availability, real HTTPS traffic through the local HTTP proxy, and absence of the legacy Python runtime. The public release set is additionally bound by a SHA-256 manifest and a detached CryptoPro/Rutoken signature made with the certificate of ООО «Арвектум».

### What to download

For a normal installation:

`Arvectum-Proxy-Launcher-0.2.5-windows-x64-setup.exe`

SHA-256:

`9b5368d67874b7164ee56a245c75db4b23af593a1d72f7e947774516abcc95e3`

For portable use:

`Arvectum-Proxy-Launcher-0.2.5-windows-x64-portable.zip`

### Windows installation

1. Download the Setup EXE from this release page.
2. Run the downloaded file.
3. Windows may show Microsoft Defender SmartScreen: **“Windows protected your PC.”** This is expected for 0.2.5 because the Setup does not yet carry a Microsoft Authenticode signature.
4. Click **More info → Run anyway**.
5. Confirm the normal UAC prompt if shown.
6. After installation, launch **Arvectum Proxy Launcher** from the Start menu.

**Do not disable Microsoft Defender, SmartScreen or Controlled Folder Access.** Disabling Windows security features is not required.

### Why SmartScreen may appear

The public 0.2.5 Setup is not Microsoft Authenticode-signed. Files downloaded from the Internet carry Mark-of-the-Web, so SmartScreen may warn about an unrecognized publisher. This warning does not mean that Microsoft Defender detected malware.

You can verify the official file with SHA-256. The release also contains a Russian detached CryptoPro/Rutoken signature and signer certificate. That layer verifies release provenance and integrity, but it does not replace Microsoft Authenticode or SmartScreen reputation.

### Verify the Setup SHA-256

```powershell
Get-FileHash "$env:USERPROFILE\Downloads\Arvectum-Proxy-Launcher-0.2.5-windows-x64-setup.exe" -Algorithm SHA256
```

Expected result:

`9b5368d67874b7164ee56a245c75db4b23af593a1d72f7e947774516abcc95e3`

### What changed in 0.2.5

- moved the canonical installed application from user Documents to `%LOCALAPPDATA%\Programs\ArvectumProxyLauncher`;
- made installer preflight observational/read-only so it does not stop the working runtime before the safe handover point;
- added stage-and-verify and transactional runtime handover with rollback/recovery;
- verified migration from the historical Documents layout;
- verified clean reboot/autostart behavior;
- the installer intentionally creates a Start menu shortcut but no Desktop shortcut;
- the final release set passed the Russian CryptoPro/Rutoken release-evidence gate before publication.

### Verify the Russian release set

For advanced verification, download all release assets into one directory and run `VERIFY_RUSSIAN_RELEASE.cmd`. It verifies the SHA-256 manifest and detached CryptoPro signature. It does not claim Microsoft Authenticode or SmartScreen trust.
