# Arvectum Proxy Launcher 0.2.11

Patch maintenance release focused on deterministic system-proxy ownership across macOS and Windows.

The already published `v0.2.10` release, tag and bytes remain immutable. 0.2.11 is a new patch release.

## Русский

### Главное

- **macOS:** устранён intermittent Safari/ChatGPT routing regression. Пока APL включён, сохранённые manual HTTP/HTTPS proxy временно выключаются, чтобы PAC Arvectum был единственным управляемым proxy-маршрутом; при OFF исходное состояние восстанавливается точно.
- **macOS acceptance:** в уже открытой вкладке Safari подтверждены HTTP 200 для главного документа ChatGPT, API и SSE/streaming; Doctor прошёл и при ON, и после rollback.
- **Windows:** существующая защита уже отключала manual WinINET proxy через `ProxyEnable=0`; теперь APL также временно устанавливает `AutoDetect=0`, исключая конкурирующий WPAD-маршрут, и точно восстанавливает сохранённое значение при OFF.
- **Linux/Astra/RED OS:** аудит подтвердил, что NetworkManager и GNOME/KDE уже переводятся в единый `auto` PAC-режим APL с точным восстановлением исходного `none/manual/auto`. Изменение Linux backend не требуется.
- **Версии:** все активные Windows/macOS/Linux build paths используют единый `VERSION=0.2.11`; исторические evidence и опубликованные версии не переписываются.

## English

### Highlights

- **macOS:** fixes intermittent Safari/ChatGPT routing by temporarily disabling saved manual HTTP/HTTPS proxy enable flags while the Arvectum PAC owns routing, then restoring the exact prior state on OFF.
- **macOS acceptance:** an existing Safari tab returned HTTP 200 for the ChatGPT main document, API traffic and SSE/streaming; Doctor passed both ON and after rollback.
- **Windows:** manual WinINET proxy isolation already used `ProxyEnable=0`; 0.2.11 also sets `AutoDetect=0` for the owned session so WPAD cannot compete with the explicit Arvectum PAC, and restores the saved value on OFF.
- **Linux/Astra/RED OS:** audit confirms NetworkManager and GNOME/KDE already converge to one APL `auto` PAC mode and restore the saved `none/manual/auto` state exactly. No Linux backend change is required.
- **Versioning:** every active Windows/macOS/Linux build path now resolves the same canonical `VERSION=0.2.11`; historical evidence and published releases remain immutable.
