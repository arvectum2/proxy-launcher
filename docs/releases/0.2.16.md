# Arvectum Proxy Launcher 0.2.16

0.2.16 is the first desktop release line in which public macOS packages are eligible only after production Apple trust promotion. Application behavior is intentionally unchanged from the physically accepted 0.2.15 macOS baseline.

## Русский

### macOS production trust

- публичные macOS Apple Silicon и Intel DMG подписываются сертификатом Developer ID Application ООО «Арвектум»;
- Hardened Runtime и Apple secure timestamp обязательны;
- нотариализация выполняется через канонический Arvectum Release Bot;
- после Apple Accepted к DMG прикрепляется notarization ticket и выполняются stapler/Gatekeeper-проверки;
- ad-hoc cloud DMG остаются только QA-входами и не публикуются как production assets.

### Без изменения функциональной логики

В 0.2.16 не меняется принятый в 0.2.15 сетевой runtime. Baseline-only macOS ExceptionsList, fail-closed wake rebind и физически проверенная Safari sleep/wake логика сохраняются без функционального расширения.

Immutable v0.2.15 не переподписывается и не заменяется. Production trust появляется только в новом релизе 0.2.16.

### Release gate

Release workflow принимает macOS assets только из exact-main production-signing workflow на доверенном Arvectum Mac mini. Для одного promotion run runner регистрируется эфемерно, выполняет одну exact-main job и удаляет регистрацию.

## English

### macOS production trust

- public Apple Silicon and Intel DMGs are signed with Arvectum's Developer ID Application identity;
- Hardened Runtime and Apple secure timestamps are mandatory;
- notarization uses the canonical Arvectum Release Bot credential;
- an Accepted notarization result is stapled and verified with Apple Gatekeeper before a DMG becomes release-eligible;
- ad-hoc cloud DMGs remain QA inputs and are never published as production assets.

### No functional routing change

0.2.16 preserves the physically accepted 0.2.15 macOS runtime: baseline-only ExceptionsList ownership, fail-closed wake rebind, and the accepted Safari sleep/wake behavior.

Immutable v0.2.15 is not re-signed or overwritten. Production Apple trust starts with the new 0.2.16 release.

### Release gate

The release workflow accepts macOS assets only from the exact-main production-signing workflow on the trusted Arvectum Mac mini. The signing runner is registered ephemerally for one promotion job and removed afterwards.
