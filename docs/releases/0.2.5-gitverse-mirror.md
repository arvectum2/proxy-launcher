- организация GitVerse: https://gitverse.ru/arvectum

Канонический набор релиза содержит 9 публичных файлов, зафиксированных в [`0.2.5-public-assets.sha256`](0.2.5-public-assets.sha256).

Внутри каждой обёртки лежит ровно один исходный файл с исходным именем и неизменным содержимым. ## English

GitVerse is maintained as an independent Russian distribution mirror for `v0.2.5`:

- GitVerse organization: https://gitverse.ru/arvectum
- repository: `proxy-launcher`; open the **Releases** tab
- canonical exact-direct release: https://github.com/arvectum2/proxy-launcher/releases/tag/v0.2.5

The governed release contains exactly 9 public files listed in [`0.2.5-public-assets.sha256`](0.2.5-public-assets.sha256).

GitVerse restricts allowed release-asset formats. Its official release documentation lists supported extensions and does not include the `.exe`, `.json`, `.sig`, `.cer`, `.cmd`, or `.ps1` extensions used by this release: https://gitverse.ru/docs/artifactory/releases-uc/

Public API probing on 2026-09-13 confirmed the same behavior: `.zip` and `.txt` uploads returned `HTTP 201`, while the unsupported extensions returned `HTTP 400 VALIDATION_ERROR`.

To preserve an independent mirror without changing canonical bytes, unsupported direct files are carried in **single-file ZIP wrappers**. Every wrapper contains exactly one canonical file under its original name. The mirror workflow downloads every published GitVerse asset through its public `browser_download_url`, extracts wrapped files, and verifies all 9 canonical SHA-256 values against the governed manifest.

This is a GitVerse transport constraint, not a product or release mutation. The original 9 files retain their canonical names, bytes and SHA-256 values.

For installation from GitVerse, download `Arvectum-Proxy-Launcher-0.2.5-windows-x64-setup.exe.zip`, extract it once, and verify the resulting EXE SHA-256:

```text
9b5368d67874b7164ee56a245c75db4b23af593a1d72f7e947774516abcc95e3
```

The portable ZIP is mirrored directly and does not require an additional transport-wrapper extraction.
