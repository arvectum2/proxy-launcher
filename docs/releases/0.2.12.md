# Arvectum Proxy Launcher 0.2.12

Patch release focused on reliable long-sleep recovery on macOS and Android.

The published v0.2.11 release, tag, and assets remain immutable. 0.2.12 is a new patch release.

## Русский

### Главное

- **macOS:** исправлен отказ связи после более долгого Sleep/Wake. APL больше не выполняет специальные wake-time перезапуски listener/relay и не форсирует закрытие туннелей после пробуждения; существующие соединения живут по обычным EOF/error/idle-timeout правилам.
- **macOS routing:** пока APL включён, системные HTTP/HTTPS настройки указывают на локальный APL proxy; исходные manual proxy, PAC и bypass-настройки сохраняются и точно восстанавливаются при OFF.
- **macOS acceptance:** физический тест на MacBook с Maintenance Sleep около 96 секунд прошёл без выключения APL и без перезапуска браузера; worker/listeners и системный маршрут остались неизменными, после wake новые CONNECT получили HTTP 200.
- **Android:** добавлено восстановление VPN-состояния после долгого сна/возврата приложения на передний план, включая reconcile живого сервиса и корректный reset, если Android отозвал VPN permission.
- **Без переписывания истории:** v0.2.11 остаётся неизменным; новый код публикуется только как v0.2.12.

## English

### Highlights

- **macOS:** fixes connectivity loss after longer Sleep/Wake cycles. APL no longer performs wake-specific listener/relay restarts or forcibly retires tunnels after resume; connections now follow normal EOF/error/idle-timeout semantics.
- **macOS routing:** while APL is ON, system HTTP/HTTPS settings point to the local APL proxy; saved manual proxy, PAC, and bypass state is preserved and restored exactly on OFF.
- **macOS acceptance:** a physical MacBook test with roughly 96 seconds of Maintenance Sleep passed without disabling APL or restarting the browser; worker/listeners and the system route stayed unchanged, and fresh post-wake CONNECT requests returned HTTP 200.
- **Android:** adds VPN-state reconciliation after long sleep/app foreground resume, including recovery of a live service and a safe reset when Android has revoked VPN permission.
- **Immutable history:** v0.2.11 remains unchanged; these fixes are published only as v0.2.12.
