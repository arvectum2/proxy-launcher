# APL iOS 0.1.41 — финальная вычитка и работающий баннер (30.10.2026)

## Подтверждённая причина и исправление

- Опубликованная iOS 0.1.40 (45) в подписанном архиве содержит YandexMobileAds 8.6.0, AppMetrica 6.7.1, `SettingsBannerView.swift` и production-блок `R-M-20288304-1`. В предыдущем локализационном кандидате 0.1.41 эти файлы и пакет отсутствовали. Восстановлены **именно из опубликованной исходной рабочей ветки**, а не воссозданы по памяти.
- Восстановлен обязательный флаг `OTHER_LDFLAGS = $(inherited) -ObjC`. Его отсутствие приводило к реальному крашу SDK при запросе тестового баннера. После исправления приложение запускается.
- Добавлены **228 актуальных SKAdNetwork идентификаторов** из официального фида `https://yastatic.net/pcode-static/skadnetwork/skadids.json` в `Config/App-Info.plist`. Без них Yandex SDK отвечал ошибкой кода 12. Источник — официальная документация `https://ads.yandex.com/helpcenter/en/dev/ios/skadnetwork`.
- Вместо `.safeAreaInset` на самом `TabView` рекламный блок теперь располагается как **отдельный нижний соседний элемент внутри ограниченного VStack**. В действительном рендере на компактном iPhone он не вытесняет нижнюю навигацию за экран. Sticky-баннер использует свой размер (не фиксированный кроп 90/100 pt), начальные 50 pt резервируются до загрузки.
- В Release используется `R-M-20288304-1`; `demo-banner-yandex` разрешён только с аргументом Debug `-APL_ENABLE_DEMO_BANNER`. На всех вкладках используется один компонент, который не запускает новые запросы при каждой смене вкладки.

## Реальные визуальные доказательства

- На iPhone SE 3 Simulator iOS 27 открыт настоящий SDK `Banner(state:)` с демо-объявлением. На немецком и иврите (RTL) в одном кадре видны статус, главная кнопка, профиль, **все четыре системные вкладки и полноценный рекламный креатив** — без прокрутки.
- Снимки и машинная проверка отдельных цветовых областей рекламы/выбранной вкладки сохранены на SSD в `/Volumes/ArvectumSSD/Arvectum/releases/APL-iOS-0.1.41-46-rsya-final-20261030/qa-live-demo/verified/` (`de`, `he`, исходные PNG 750×1334).
- Оригинальная матрица из 380 проверок для 50 языков с геометрией тестового баннера (90–100 pt) остаётся пригодной для контроля размеров карточек и шрифтов. Теперь к ней добавлена именно **SDK-интеграционная** проверка, отсутствовавшая до исправления.
- Единичные быстрые скриншоты после перезапуска (3 сек) могут захватить только локализованную метку без загруженного креатива: фактическая загрузка из сети асинхронна. Такие скриншоты **не считались доказательством показа**. Два успешных кадра получены при завершённой загрузке SDK.

## Редакторская вычитка iOS

- Сохранены 50 системных языковых каталогов по 155 строк = **7750 UI-значений**. Полный аудит структуры, подстановок, ключей и ошибочных фрагментов английского в чужих локалях: **0 ошибок**.
- Во всех 50 локализациях переписаны **два пользовательских поясняющих значения**: теперь они ясно говорят о возможности настройки собственного прокси без регистрации и о локальном хранении реквизитов подключения.
- Вручную исправлены **22 смысловые и UI-терминологические ошибки** в 15 языках. Примеры: польское `Ratować` → `Zapisz`, нидерландское `Redden` → `Opslaan`, малайское `Jimat` → `Simpan`, вьетнамское `Cứu` → `Lưu`; поправлены глаголы управления и термин «исключения».
- Добавлены **50 отдельных локальных названий рекламной метки** (рус. «Реклама», англ. «Ad», иврит «פרסומת», араб. «إعلان» и остальные), без изменения ключевой схемы 155 строк.
- Проверены локализованные названия ключевых кнопок, статусных состояний, Host/Port, профилей и исключений во всех 50 языках; исправления не затрагивают host/IP, URL, placeholders и VPN-протоколы.
- Сохранены 47 подготовленных официальных App Store ASO-вариантов, 94 скриншота и соответствие Apple ограничениям: название/подзаголовок ≤30, промотекст ≤170, ключевые слова ≤100 байт UTF-8.
- Вычитка и формулировки выполнены средствами ChatGPT с автоматическим контролем исходных каталогов; независимый внешний переводчик-носитель не привлекался.
