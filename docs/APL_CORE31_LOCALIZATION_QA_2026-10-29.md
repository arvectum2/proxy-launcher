# APL Core-31 — маратхи, гуджарати, каннада, малаялам, узбекский (латиница)

29 октября 2026 г. Отдельная волна локализации в существующем PR #272; ни App Store Connect, ни уже отправленная Apple сборка не изменены.

## Корпус

- Пять новых языков второго уровня из реестра `arvectum-tools/core/localization/portfolio-locales.json`: `mr`, `gu`, `kn`, `ml`, `uz` (латинская письменность).
- Каждый: **155 iOS + 104 Android + 193 desktop = 452 строки**. Новая волна **2 260 строк**, общий каталог **31 язык × 452 = 14 012 локализованных значений**.
- Полные файлы `mobile/ios/Resources/{mr,gu,kn,ml,uz}.lproj/Localizable.strings`; Android `values-mr`, `values-gu`, `values-kn`, `values-ml`, `values-b+uz+Latn`; desktop `desktop_i18n.CATALOGS`; iOS `AppLanguage` и OS-language matching. В пользовательском переключателе узбекский называется `Oʻzbekcha (lotin)`; iOS/desktop автоматически не подставляют эту латинскую локаль для явно кириллической `uz-Cyrl`.
- Первичный полный перевод выполнен пакетно по исходным английским строкам с техническими масками, последующая модельная редакторская правка **80 важных инструкций** (16 на язык): onboarding, VPN-согласия, исключения, Shortcuts и режимы подключения. Проверены **28 технических терминов × 5 языков** в общем глоссарии.
- Вычитаны **20 критичных настольных сообщений** (по 4 на язык): восстановление сети, невозможность подтвердить прошлую сессию, неприкосновенность чужих настроек и неполное восстановление после остановки. Текст кнопок дословно соответствует инструкциям. Для фрагментированных строк UI сохранены граничные пробелы.
- Английский fallback, все существующие 26 переводов, RTL для `ar`/`fa`/`ur`, работа прокси, PAC и сетевые конфигурации не изменялись.

## Проверки

- Контракт `tests/test_core31_expansion.py` и предыдущие источниковые QA: **25/25 PASS** в каждом из пяти новых языковых контекстов. Нет пустых строк, потери ключей и разницы в динамических форматах.
- Полный Python regression с `APL_UI_LANGUAGE=uz`: **1295 passed, 6 skipped, 3 deselected, 113 subtests passed**. Три старых, не относящихся к локализации Windows maintenance contract теста исключены в соответствии с предыдущими циклами.
- iOS: `xcodegen`, typecheck `AppLocalization.swift`, `plutil` для **31** `.strings` PASS. Неподписанная UI-only сборка для iOS Simulator **BUILD SUCCEEDED**, в `.app` ровно **31** `.lproj`. Подписанный VPN `PacketTunnel` архив не собирался.
- Android JDK17: `compilePublicDebugKotlin`, `compilePrivateDebugKotlin`, `testPublicDebugUnitTest`, `testPrivateDebugUnitTest` — **BUILD SUCCESSFUL** (49 Gradle tasks).
- `git diff --check` PASS; пользовательская карточка Apple и её условия конфиденциальности оставлены как были, Watchdog не создавался.

## Границы результата

Это полноценный комплект исходных переводов с модельной редактурой, но не независимая профессиональная вычитка носителями. Перед публикацией необходимы физические UX-проверки переполнения строк и accessibility, в том числе шрифты сложных письменностей и имена Shortcuts, а также контроль соответствия узбекской латиницы. Проектная задача source-localization выполнена, новая версия Apple не отправлялась. PR не объединять автоматически.
