# APL iOS — быстрые команды VPN (исходники, 31 октября 2026)

Реализованы явные пользовательские Shortcuts App Intents для iOS 16+: `ConnectAPLIntent`, `DisconnectAPLIntent`, `ToggleAPLIntent`. Их можно найти в Apple «Команды», добавить на экран «Домой» или запускать из автоматизации. Прежние `SelectedAppOpenedIntent` / `SelectedAppClosedIntent` сохранены.

- Команды читают реальный статус `VPNController`; повторное «подключить» уже активный VPN и «отключить» отключённый — без изменения состояния. При активном отключении `Toggle` выдаёт объяснимую ошибку, не принимает противоположное решение по старому статусу.
- Одновременные быстрые команды в одном процессе защищены main-actor флагом. Запрос отключения ожидает подтверждения NetworkExtension (до 10 секунд); подключение инициирует системный VPN, но фактическую работоспособность трафика проверяют отдельно.
- Сохранение профилей/импорт/покупка/маршрутизация сайтов от Shortcuts не меняются. При отсутствии профиля или разрешения iOS возвращается системная ошибка. Ни одна команда не исполняется при рендеринге виджета/чтении состояния.
- В настройках iOS 16+ появляется раздел помощи с ссылкой `shortcuts://`; введена отдельная таблица `QuickActions.strings` на 16 языках с английским fallback для остальных. Существующие 50 каталогов iOS×155 ключей остаются неизменными, опубликованная Apple 0.1.41 не затронута.
- Не добавлен Control Center Widget / Home Screen Widget: отдельное WidgetKit-extension, iOS-entitlements и реальная аппаратная проверка нужны для интерактивного виджета. Существующие App Intents могут быть использованы в пользовательских ярлыках «Команд» без виджета APL.

## Регрессионные проверки

- [x] Чистая Swift-политика Connect/Disconnect/Toggle и переходных состояний, отдельные XCTest.
- [x] 16 таблиц `QuickActions.strings` по три записи, 50 исходных `Localizable.strings` не изменены.
- [x] iOS Simulator Debug app build и `QuickActionsUITests` (English, без реального изменения VPN).
- [ ] Прямая проверка регистрации системных App Shortcuts, запуска подключить/отключить/toggle на iPhone, системных разрешений VPN и сохранения профиля — вместе с полной приёмкой следующей версии.

Не трогать заявку Apple iOS 0.1.41 или macOS 0.2.20.
