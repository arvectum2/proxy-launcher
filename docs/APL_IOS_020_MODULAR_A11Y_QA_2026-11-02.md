# APL iOS 0.2.0 — модульный UI и доступность до выпуска

Дата: 02.11.2026. Изолированная ветка `feat/ios-020-product-plan-20261101`, Draft PR #296. Предыдущая версия Apple находится в ожидании публикации: этот этап **не является релизом**.

## 1. Выделение компонентов без изменения модели

`ContentView.swift` уменьшен с **1500 до 1122 строк** (−378, около четверти файла). Выделены:

- `CompactSettingsView.swift` — компактный экран настроек iPhone, получает **те же** `@Binding` для темы/языка/открываемых окон и **один** `@ObservedObject AppViewModel`; не создаёт вторую базу профилей, VPNController или туннель.
- `ActivityScreenView.swift` — события/статус, чтение из той же `AppViewModel`, обновление по кнопке и при открытии. Не содержит подключения VPN или записи профилей.
- `BrandTheme.swift` — семантическая динамическая палитра и оригинальные фирменные ресурсы.
- `AppDestination.swift` — четыре вкладки, их локализованные названия и SF Symbols; первая — «Домой».
- `EqualHeightDashboardLayout.swift` — отдельная Mac Catalyst-логика равновысоких карточек (только Catalyst, недоступна в iOS сборке).

Удалены два неиспользуемых приватных `ButtonStyle`; текущие visual modifiers и пользовательские действия сохранены. Документы, VPN/NetworkExtension, РСЯ, AppMetrica, локализации, Apple Store и сохранённые профили не изменялись.

## 2. Dynamic Type / Accessibility

- Стандартный iPhone: **настройки по-прежнему полностью помещаются на экран** без вертикального скролла; тема — сегментированный переключатель, язык — компактное меню, остальные кнопки и тумблер сохраняют расположение.
- При размерах шрифта `Accessibility XXL`: строки «Тема» и «Язык» переходят из горизонтального ряда в вертикальный формат **название → значение**, чтобы немецкие, арабские и длинные другие локализованные названия не усекались. Тема автоматически становится меню вместо неподходящего трёхсекционного segmented control.
- Поверхность настройки имеет **минимальную** высоту 44 pt, но может увеличиваться по содержимому. Иконки при XXL имеют контролируемый размер и не перекрывают надписи, длинные тексты допускают три строки. `ViewThatFits` использует scrollable fallback, не обрезая настройки.
- На «Активности» при XXL длинный локализованный текст о VPN размещается **над** кнопкой «Обновить», а не делит с ней узкую строку. Кнопка имеет не менее 44×44 pt. Строки событий объединены для VoiceOver в одно осмысленное описание.
- Для темы, языка и приоритетного прокси добавлены явные локализованные accessibility labels; для кнопок действий сохранены стабильные accessibility identifiers. Дополнительно при Accessibility-размере версия в хэдере скрыта, чтобы не усекать название Arvectum Proxy Launcher — версия остаётся в настройках.
- Кнопки «Добавить / Импорт / Копия» теперь имеют `minHeight` вместо жёсткой высоты 46 pt и могут расти с Dynamic Type.

Первоначальные визуально обнаруженные усечения темы/языка и стеснение статуса VPN **исправлены**, скриншоты повторного запуска подтверждают отсутствие этих проблем.

- Текущие 50 `.lproj` проверены без каких-либо изменений: `scripts/ios_020_locale_audit.py` по-прежнему сообщает **0 ресурсных ошибок, 0 новых английских fallback**.

- **Малый iPhone SE 3-го поколения**: такой же подписанный read-only UI-XCTest с `Accessibility XXL`, `de` и `ar`, Settings и Activity: **1/1 PASS, 33,723 с**. Все кнопки и тумблер доступны прокруткой, 44 pt tap-target подтверждён, шесть снимков экспортированы. Визуально проверены крайние состояния: английские/немецкие тексты темы и языка не усечены, арабский текст возврата к основному может занимать несколько строк, но не скрывается за таббаром и доступен при скролле. После проверки системный размер шрифта установлен обратно в `large`, тестовый SE завершён, исходный iPhone 13 Simulator восстановлен.

Ручная приёмка системным VoiceOver на физическом телефоне (управление жестами и реальная речь) **не подменяется** `XCUITest`-проверкой accessibility labels и остаётся отдельной задачей.

## 4. Релизная граница

Ветка и Draft PR остаются **без merge и публикации**, App Store Connect и metadata не затрагиваются, iPhone не переустанавливается и не запускает VPN ради рефакторинга. Подписанная Apple Distribution IPA от локализационного этапа **предшествует этим изменениям**; если владелец позже разрешит выпуск, надо заново собрать релизный архив из утверждённого исходного кода.

В очереди остаются дальнейшая декомпозиция объёмного экрана «Профили», расширенная аппаратная приёмка реального proxy egress/failover с согласованными тестовыми прокси, и отдельная P2-синхронизация исключений через iCloud (для неё не создавались CloudKit entitlements и не запускалась разработка).
