# APL iOS 0.2.0 — рефакторинг списка профилей до публикации

Дата: 02.11.2026. Ветка `feat/ios-020-product-plan-20261101`, существующий Draft PR #296. Релиз, метаданные Apple, AppMetrica/РСЯ, VPN и реальные данные пользователя не изменялись.

## 1. Архитектура

`ContentView.swift` сокращён с **1122 до 850 строк** (ещё −272), оставлен координатором общих вкладок и sheet-окон. Вместо встроенного блока «Профили» используется `ProfilesScreenView` с явными `@Binding` к созданию/редактированию/резервным копиям и callback к прежнему импорту. Выделены:

- `ProfilesScreenView.swift`: организация списка, transient search/selection state, alerts для создания группы и подтверждения удаления; **одна `@ObservedObject AppViewModel`**, без собственной БД, VPN и Keychain.
- `ProfileLibraryFiltersView.swift`: поиск, избранное/группы, ручная ограниченная проверка, локальный focus клавиатуры и мультивыбор.
- `ProfileLibraryRowView.swift`: строка профиля, избранное, выбранный профиль, качество подключения, исходный `host:port` с принудительным LTR внутри арабского/иврита; `ProfileLibraryGroupMenu` единообразен для строки и массовых операций.
- `ProfileLibraryBulkActionsView.swift`: выбор всех, снятие выбора, добавление/снятие избранного, группы, ограниченная диагностика и подтверждаемое удаление.
- `SharedCore/ProfileLibrarySelectionPolicy.swift`: **чистая тестируемая политика** поиска/фильтрации/сортировки и пересечения выбранных UUID с **текущим видимым набором**. Не содержит хранения/сетевых действий.

При изменении строки поиска или фильтра выделение очищается; при удалении/импорте из выделения удаляются устаревшие UUID. Удаление повторно проверяет, что VPN не активен. Отправлять на проверку можно не более **10** выбранных видимых профилей. Опасное массовое действие использует **только пересечение выбранных с видимыми**, в том числе если фильтр изменился до подтверждения.

## 2. UI / Dynamic Type

Основная компоновка «Добавить / Импорт / Копия» при обычном системном шрифте остаётся в одном ряду. При Accessibility XXL на маленьком iPhone SE кнопки становятся вертикальными во всю ширину для предотвращения усечения длинных немецких и арабских переводов. Заголовок и кнопка выбора также становятся вертикальными, массовые действия — адаптивным списком. У интерактивных элементов сохранены стабильные `profiles.*` accessibility identifiers и минимальная зона нажатия 44 pt. Никаких новых переводимых строк не вводилось — все 50 локализаций сохранены.

## 4. Релизная граница

Изменения находятся **только в Draft PR**, без merge и TestFlight/App Store upload. Физический iPhone и пользовательские 3 профиля не изменяли. Уже собранная предыдущая Apple Distribution IPA не содержит этот новый рефакторинг: при будущем санкционированном выпуске пересобрать архив из утверждённого исходного кода. Отдельно остаются живые upstream egress/failover, реальная проверка системным VoiceOver и P2 iCloud-синхронизация исключений.
