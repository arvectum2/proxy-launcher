# APL Core-21 · локализации hi/ar/vi/pl/th

Дата: 29.10.2026. Текущая ветка PR #272; публикации App Store не затрагивались.

## Объём

- Добавлены пять полных исходных языков первого уровня из реестра Arvectum Tools Core: хинди (`hi`), арабский (`ar`), вьетнамский (`vi`), польский (`pl`), тайский (`th`).
- На каждом языке **155 iOS + 104 Android + 193 desktop = 452 строки**; новая волна **2260 строк**, общий охват **21 язык, 9492 локализованных исходных значения** на трёх платформах.
- `AppLanguage` (iOS picker и системная локаль), локализационные `.lproj`, Android `values-hi/ar/vi/pl/th`, `desktop_i18n` плюс 28 технических терминов глоссария на каждом новом языке.
- Отдельно отредактированы **80 длинных фраз** (по 16 на язык): первоначальная настройка, Apple Shortcuts, состояние соединения, исключения, настройки оформления, переключение режимов, системные VPN-разрешения. Исправлены пять сообщений о безопасном восстановлении сети с буквальным совпадением названия кнопки. Термины *proxy, port, host, type, log, auto* исправлены в сквозном глоссарии для предотвращения дословных ошибок машинного перевода.
- iOS: для арабского и фарси автоматическое RTL (`layoutDirection=rightToLeft`). Android: `supportsRtl=true` и отдельный LTR для ввода адреса сайта, host/IP и номера порта (чтобы цифры и двоеточие не менялись местами). Desktop: арабский и фарси в RTL-ориентированном выравнивании Tk; **полное зеркалирование геометрии Tk не заявлено**.

## Проверки, 29.10.2026

- Структура и параметры всех 21 языков: **21 focused locale tests PASS**; отдельные тесты на арабский RTL и точные надписи для восстановления.
- Полный Python-набор с `APL_UI_LANGUAGE=ar`: **1291 passed, 6 skipped, 3 deselected** (три старые несвязанные Windows maintenance cases), **113 subtests passed**. Проверка целевых локалей при `APL_UI_LANGUAGE=hi/ar/vi/pl/th`: по 21 focused PASS.
- iOS: `xcodegen`, Swift localization simulator typecheck, `plutil` всех **21** Apple `.strings` PASS; неподписанная **UI-only** arm64 iOS Simulator **BUILD SUCCEEDED**, в .app найдено **21** `.lproj`. Это не signed PacketTunnel archive.
- Android: `compilePublicDebugKotlin`, `compilePrivateDebugKotlin`, `testPublicDebugUnitTest`, `testPrivateDebugUnitTest` с JDK17, Gradle **BUILD SUCCESSFUL** (49 задач).
- Сетевые маршруты, конфигурации прокси, PAC, протоколы и релизные настройки не менялись; отдельно от локализации внесена только технически необходимая защита полей host/port от RTL перестановок.
