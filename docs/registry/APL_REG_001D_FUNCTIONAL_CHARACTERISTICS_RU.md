# APL-REG-001D — функциональные характеристики

## 1. Наименование и назначение

**Arvectum Proxy Launcher 0.2.9** — локальное кроссплатформенное desktop-приложение для управления системными proxy/PAC-настройками и восстановления сетевой конфигурации пользователя.

Основной сценарий: пользователь указывает внешний upstream proxy, включает Proxy Launcher, а приложения получают управляемый системный proxy/PAC и локальные HTTP/SOCKS5 endpoint'ы. При выключении, сбое или восстановлении программа возвращает только те параметры, происхождение которых может доказать как исходное или применённое самой программой.

## 2. Основные функции

- настройка системного proxy/PAC для поддерживаемой пользовательской среды;
- управление `no_proxy` / bypass-исключениями;
- локальные HTTP и SOCKS5 endpoint'ы для подключения клиентских приложений;
- хранение исходного состояния управляемых сетевых параметров;
- штатный rollback при отключении;
- crash/reboot recovery при наличии незавершённого rollback evidence;
- защита от перезаписи стороннего состояния: неизвестное третье значение приводит к fail-closed вместо destructive restore;
- диагностика текущего состояния и платформы;
- пользовательский lifecycle через графический интерфейс и системную интеграцию соответствующей ОС.

## 3. Поддерживаемые платформы релиза 0.2.9

- Microsoft Windows x64 — Setup и portable;
- Astra Linux 1.8 x86-64 / Fly, NetworkManager + GSettings;
- RED ОС 8.0.3 x86-64 / KDE Plasma.

Для Astra Linux пакет имеет формат DEB, для RED ОС — RPM. Linux-бинарь запускается командой `arvectum-proxy-launcher` после установки пакета.

## 4. Архитектурные границы

Продукт:

- работает как пользовательское desktop ПО;
- не является операционной системой;
- не является VPN-клиентом/шлюзом, маршрутизатором или межсетевым экраном;
- не заявляется как сертифицированное средство защиты информации;
- не включает собственную коммерческую proxy-инфраструктуру;
- не требует облачного control plane для базовой локальной работы;
- не требует лицензионного/активационного сервера;
- не является ПАК.

Upstream proxy является внешним ресурсом, адрес и учётные данные которого определяет пользователь или заказчик.

## 5. Сетевое поведение

Локальные сервисные endpoint'ы предназначены для loopback/local use. Программа публикует системные proxy-настройки в механизмах поддерживаемой ОС/desktop environment. На Linux lifecycle связан с NetworkManager; на Astra/Fly используется также GSettings, на RED ОС/KDE — соответствующая desktop-интеграция. На Windows управляются пользовательские WinINET и proxy environment значения в пределах модели релиза.

Программа не должна отключать антивирус, firewall, SmartScreen или иные защитные механизмы ОС для установки и работы.

## 6. Надёжность rollback/recovery

Ключевое свойство 0.2.x — сохранение доказуемого baseline перед изменением системных параметров. Перед destructive restore проверяется, что текущее значение является либо сохранённым исходным, либо значением, ранее применённым Arvectum. Третье/неизвестное значение трактуется как внешнее изменение и не перезаписывается автоматически.

Эта модель проверялась физически на Astra Linux и RED ОС для Linux-поведения линии 0.2.8; в 0.2.9 Linux-поведение заявлено release notes как неизменённое. Для регистрационного экземпляра точные публичные DEB/RPM `v0.2.9` должны пройти финальный version gate, описанный в `APL_REG_001F_PRE_SUBMISSION_AUDIT.md`.

## 7. Минимальные системные требования

### Windows

- x64 Windows, поддерживающая пользовательский WinINET/system proxy stack;
- права текущего пользователя на установку per-user Setup либо запуск portable-пакета;
- сетевой доступ к настроенному пользователем upstream proxy для фактической проксированной передачи данных.

### Astra Linux

- Astra Linux 1.8 x86-64;
- NetworkManager;
- GSettings / `libglib2.0-bin` для desktop proxy integration;
- административные права на установку DEB-пакета.

### RED ОС

- RED ОС 8.0.3 x86-64 / KDE Plasma;
- системный пакетный менеджер RPM/DNF;
- NetworkManager и desktop proxy integration, предусмотренные целевой системой;
- административные права на установку RPM-пакета.
