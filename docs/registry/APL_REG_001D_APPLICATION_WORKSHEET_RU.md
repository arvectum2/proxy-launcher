## Текст «Функциональные характеристики»

> Arvectum Proxy Launcher — локальное кроссплатформенное программное обеспечение для управления пользовательскими сетевыми proxy-настройками. Программа конфигурирует системный proxy/PAC и `no_proxy`, предоставляет локальные HTTP/SOCKS5 endpoint'ы для подключения приложений к заданному пользователем внешнему proxy и сохраняет доказуемое исходное состояние сетевых настроек для безопасного отключения и аварийного восстановления. При обнаружении стороннего изменения управляемых параметров destructive rollback выполняется fail-closed, без перезаписи неизвестного состояния.

## Текст «Назначение»

> Назначение программы — централизовать для пользователя включение, отключение и восстановление системных proxy-настроек рабочего места при использовании внешнего proxy-сервера, снизив риск остаточной или повреждённой сетевой конфигурации после штатного завершения, сбоя или перезагрузки.
