Этот каталог отделяет воспроизводимую техническую часть заявки от закрытых корпоративных документов. В публичный репозиторий не должны попадать паспортные данные, ИНН/ОГРН вне уже публично утверждённого контекста, доверенности, УКЭП/ключевой материал, подписанные договоры об отчуждении прав, банковские сведения и иные закрытые доказательства.

## Критический version gate

Физическое acceptance RED ОС было закрыто на точном публичном `v0.2.8`; релиз `v0.2.9` изменил Windows rollback/recovery и, согласно release notes, сохранил Linux-поведение `v0.2.8` без изменений. До отправки заявки выбрать и документировать один из двух безопасных путей:

1. выполнить короткий физический smoke/acceptance **точных публичных `v0.2.9` DEB и RPM** на Astra Linux SE и RED ОС; предпочтительный путь;
2. если экспертно/юридически принято доказательство неизменности Linux payload/code между `0.2.8` и `0.2.9`, оформить отдельную traceability-записку с commit/artifact lineage.

Пока один из путей не закрыт, пакет не маркируется `READY TO FILE`.
