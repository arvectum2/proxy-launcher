Arvectum Proxy Launcher — Windows Installation and Support
=========================================================

RECOMMENDED: WINDOWS INSTALLER

1. Download the current Windows setup file from the canonical GitHub Release:
     Arvectum-Proxy-Launcher-X.Y.Z-windows-x64-setup.exe
2. Verify the published SHA-256 checksum before running the installer.
3. Run Setup as the same Windows user who will use the Launcher. Administrator rights
   are not required by the standard per-user installation.
4. Start "Arvectum Proxy Launcher" from the Start menu.
5. Configure the upstream proxy and verify connectivity before enabling autostart.

The installed application is kept under the per-user LocalAppData Programs directory:
  %LOCALAPPDATA%\Programs\ArvectumProxyLauncher

Persistent settings, no-proxy rules, logs and recovery state are kept under:
  %LOCALAPPDATA%\Arvectum\ProxyLauncher

Versions before 0.2.5 could use this historical executable location:
  %USERPROFILE%\Documents\ArvectumProxyLauncher

That Documents path is retained only as a migration/ownership source. Current Setup does
not install there. This avoids relying on a user folder that Windows Controlled Folder
Access may protect. Setup also does not create a Desktop shortcut by default; use the
Start-menu shortcut instead.

UPGRADE

To upgrade, download a newer canonical Setup and run it as the same Windows user.
The installer verifies the embedded application payload and performs a read-only
maintenance preflight before touching the running proxy. The incoming application is
staged and hash-verified before the live runtime/network handover. Only after ordinary
Setup writes have completed does the installer stop/roll back the owned previous runtime,
commit the replacement and, when the previous proxy was active, start and verify the new
runtime. If the late handover fails, the replacement is rolled back and the installer
attempts to restore the previous working runtime without discarding recovery evidence.
Persistent user configuration is preserved.

REPAIR

Use the Start menu shortcut:
  Repair Arvectum Proxy Launcher

The cached repair Setup restores damaged application files and removes stale owned
maintenance/runtime artifacts without deleting persistent proxy configuration.
If network recovery backups are still pending and safe rollback cannot be proven,
repair fails closed instead of discarding recovery state.

UNINSTALL

Uninstall from Windows Settings > Apps > Installed apps, or use the normal Inno Setup
uninstaller. Uninstall removes the application and startup state that can be proven to
belong to Arvectum Proxy Launcher. Persistent user configuration is intentionally kept.
A foreign startup entry is not removed merely because it uses a similar name.

WINDOWS PORTABLE

For the portable ZIP:
  Arvectum-Proxy-Launcher-X.Y.Z-windows-x64-portable.zip

Extract the ZIP into a normal writable folder and run "Arvectum Proxy Launcher.exe".
The package includes its own README.txt and SHA256SUMS.txt. When Windows permits the
stable handoff, the Launcher uses the same canonical LocalAppData Programs location and
persistent state directory as the installer. The pre-0.2.5 Documents location remains a
recognized legacy source only. If stable-copy creation is blocked, the current portable
session can continue but autostart remains disabled.

DIAGNOSTICS AND SUPPORT

The executable provides read-only diagnostics:
  "Arvectum Proxy Launcher.exe" --doctor
  "Arvectum Proxy Launcher.exe" --doctor-json <output.json>

Useful support evidence includes:
  %LOCALAPPDATA%\Arvectum\ProxyLauncher\install.log
  the Doctor output, if requested
  the exact application version
  the SHA-256 of the downloaded package

Do not publish proxy credentials, tokens, passwords or unredacted secrets in a support
request. Diagnostic/support tooling is designed to redact secrets, but inspect any
bundle before sending it outside your organization.

SAFETY AND RECOVERY

* Do not delete the LocalAppData state directory while the proxy is active or recovery
  is pending.
* Saved upstream passwords are protected for the current Windows user with DPAPI.
* Use the Launcher's recovery path first. Manual deletion of backup/recovery files can
  make safe rollback impossible.
* Installation, upgrade, repair and uninstall are designed to modify only state whose
  ownership can be proven; ambiguous/foreign startup state is preserved.

INTEGRITY AND SIGNING

The Arvectum icon and Windows version metadata identify the product but are not a digital
signature. Production Russian release-evidence signing is governed separately by
RELEASE_POLICY.md and the APL-REL signing track. Verify release bytes against the
published SHA256SUMS.txt and obtain packages only from the canonical release channel.
