Arvectum Proxy Launcher — Third-Party Notices
============================================

This notice distinguishes components that may be distributed inside a platform
artifact from build-only tooling and operating-system-provided components. The
final release SBOM remains the source of truth for the exact payload of a given
artifact.

Python / Python standard library
--------------------------------
Copyright Python Software Foundation and contributors. Licensed under the
Python Software Foundation License. Python runtime components are frozen into
PyInstaller desktop artifacts as selected by the platform build.

Tcl/Tk
------
Copyright Tcl/Tk contributors. Tcl/Tk is distributed under BSD-style license
terms and is used by Tkinter GUI builds when included by the selected Python /
PyInstaller runtime.

PyInstaller
-----------
Copyright PyInstaller Development Team. PyInstaller is licensed under
GPL-2.0-or-later with the project's special exception permitting distribution
of bundled applications. PyInstaller is primarily build tooling; its generated
bootloader/runtime contribution may be present in frozen artifacts.

AppImage type-2 runtime — Linux AppImage only
----------------------------------------------
The Linux AppImage artifact includes the separately hash-pinned AppImage type-2
runtime. The upstream runtime project is MIT licensed and documents statically
linked third-party code from musl libc, libfuse, squashfuse, libzstd and zlib.
The exact pinned runtime Makefile also links mimalloc; Arvectum records that MIT
notice explicitly even though it is not enumerated in the upstream runtime
LICENSE. The exact runtime SHA-256 and source commit used by Arvectum are
recorded in tools/appimage-toolchain.lock.

Promoted AppImages embed a hash-bound APPIMAGE_RUNTIME_LICENSES manifest and are
published together with a corresponding-source companion containing the exact
type2-runtime source commit and pinned libfuse/squashfuse source inputs. This
runtime is not present in the Debian .deb package.

Build-only tooling
------------------
The exact Python build dependency set is pinned in requirements-build.lock.txt.
Inno Setup is used for the Windows installer path. appimagetool is used to
construct the Linux AppImage. Apple hdiutil is used to construct macOS DMGs.
Build-only tools are not claimed as application runtime components unless the
final artifact/SBOM demonstrates that code from them is distributed.

Operating-system components
---------------------------
Windows APIs/PowerShell, Linux NetworkManager/PolicyKit and Apple macOS system
tools are host/platform dependencies and are not redistributed as Arvectum
source code by this repository.

Release rule
------------
Before a production release, reconcile this notice with the generated SBOM and
the actual platform artifact. If they disagree, the release must be held until
the notice/provenance package is corrected.
